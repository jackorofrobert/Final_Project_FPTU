2. Offline Training Workflow

Training loads datasets, normalizes columns, caches to history, trains model. 

graph TB
    A[Datasets] --> B[Scanner]
    B --> C[Loader]
    C --> D[Normalize]
    D --> E[Cache]
    E --> F[Merge]
    F --> G[Clean Text]
    G --> H[Features]
    H --> I[Train XGBoost]
    I --> J[Evaluate]

4. Online Prediction Workflow - Ensemble Score

Real-time prediction combines ML model with feature-based risk analysis. 

graph TB
    A[Email Text] --> B[Normalize]
    B --> C[Features]
    C --> D[Text/TFIDF]
    C --> E[Urgent Keywords]
    C --> F[Links Count]
    C --> G[Sender Domain]
    D --> H[XGBoost - 70%]
    E --> I[Urgent Risk - 12%]
    F --> J[Links Risk - 10.5%]
    G --> K[Sender Risk - 7.5%]
    H --> L[Sum Scores]
    I --> L
    J --> L
    K --> L
    L --> M{Ensemble Score}
    M -->|Below 50%| N[LEGITIMATE]
    M -->|50% to 70%| O[SUSPICIOUS]
    M -->|Above 70%| P[PHISHING]
Ensemble Formula: Score = Model×0.70 + Urgent×0.12 + Links×0.105 + Sender×0.075
Thresholds: LEGITIMATE: <50% | SUSPICIOUS: 50-70% | PHISHING: >=70%
